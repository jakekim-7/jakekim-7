# Personal Portfolio

개인 이력, 경력, 프로젝트, 자격증, 수상경력을 한 곳에서 관리하기 위한 확장형 포트폴리오입니다.

## 구조
- `index.html`: 포트폴리오 화면
- `portfolio-data.js`: 이력/자격증/수상/프로젝트 데이터
- `projects/`: 실제 프로젝트 파일을 연결하거나 보관할 공간

## 현재 연결된 프로젝트
